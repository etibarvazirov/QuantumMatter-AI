# QuantumMatter AI
Extract the archive. Run `pip install -r requirements.txt` then `streamlit run app.py` (Python 3.13 recommended). For Streamlit Community Cloud upload the contents to a GitHub repository, choose app.py and Python 3.13. If exact training dependency versions are unavailable on the deployment platform, do not silently downgrade; verify predictions first. No training or API keys required. The nine JSON models are the original Stage 9 models. The app is a research prototype, not a physical quantum simulation or experimental solar cell efficiency predictor. Interface is primarily English; language selector translates introductory guidance only. Dataset source: CEPDB mirror listed in app; verify redistribution permissions before publishing data or models. Reference examples are held-out dataset molecules, not novel discoveries.
